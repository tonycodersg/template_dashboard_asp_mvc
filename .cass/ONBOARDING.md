## What this repo does

This is an admin dashboard template built on ASP.NET Core 8.0 MVC and Razor Pages. It has a clean, responsive UI and pre-built admin pages: Dashboard, User Management, Settings and Configuration. The design is based on the Betall Notification Dashboard. You fork it and customize it as the starting point for your own admin back-office.

The repo also ships AI-assistant support. `.github/copilot-instructions.md` holds coding guidelines, `.prompts/` holds reusable prompt templates (create-admin-page, add-component, update-sidebar), and `.mcp/` holds GitHub and Jira MCP server configuration with a setup guide.

## How to set up locally

1. Install the [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later. Use Visual Studio 2022, VS Code or JetBrains Rider as your editor.
2. Change into the project directory: `cd AdminDashboardTemplate/Dashboard`
3. Restore and build: `dotnet restore` then `dotnet build`
4. Run the app with `dotnet run`, or with hot reload (recommended) using `dotnet watch run`.
5. Open http://localhost:5120. The app is HTTP-only, so no HTTPS certificate is needed.
6. If you use the SQL Server / EF Core parts, configure a connection string in `appsettings.Development.json`. The README does not document one.

Pages to check:
- `/` (Home)
- `/Privacy`
- `/Admin`
- `/Admin/Users`
- `/Admin/Settings`
- `/Admin/Configuration`

## Customization cheat sheet

- **Sidebar menu:** edit `Views/Shared/_AdminLayout.cshtml` or `Pages/Shared/_AdminLayout.cshtml`.
- **Styles:** add to `wwwroot/css/admin-site.css`.
- **Scripts:** add to `wwwroot/js/admin-site.js`.
- **New admin page:** add an action in `Controllers/AdminController.cs` and a view in `Views/Admin/`. Views pick up the admin layout through `_ViewStart.cshtml`.
- **Troubleshooting:** if views do not update, use `dotnet watch run`. If CSS or JS does not load, check that the files exist in `wwwroot/` and look for 404s in the browser console.
